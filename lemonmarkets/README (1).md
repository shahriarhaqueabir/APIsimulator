# Lemon Markets Sandbox Lifecycle Dashboard --- Agentic Development Documentation

This documentation set is the development baseline for an agentic AI
tasked with building the application.

## Documents

1.  **Part 1 --- Product & Functional Specification**
    -   Defines the product goal, lifecycle, UI behaviour, functional
        scope, UX principles, and acceptance criteria.
2.  **Part 2 --- Technical Architecture & Engineering Specification**
    -   Defines the frontend/backend architecture, technology stack,
        state management, API boundary, event model, security, testing,
        and technical definition of done.
3.  **Part 3 --- Agentic Development Playbook**
    -   Defines how an autonomous development agent should inspect,
        plan, implement, test, review, and release the application.

## Important source-of-truth rule

The architecture illustration is a conceptual product/system reference.
Exact Lemon Markets API endpoints, schemas, authentication, sandbox
behaviour, and event mechanisms must be verified against the current
official API documentation before implementation.
